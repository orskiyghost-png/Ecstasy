# Дизайн-система

## Статус и источник

Целевое визуальное направление из `telegram_ai_mini_app_prompt.md.txt`, раздел 8. Отдельное изображение-референс в текущей структуре репозитория не найдено; исходный промпт описывает его текстом. Ничего не считается реализованным.

## Направление

- Тёмный, спокойный premium SaaS.
- Иерархия через типографику, отступы и контраст.
- Тонкие границы, умеренные скругления, сдержанный фиолетовый акцент.
- Mobile-first для Telegram WebView; на широком экране — компактная навигация и рабочая область.
- Учитывать safe areas, фактическую высоту WebView, клавиатуру и Telegram theme parameters.
- Не использовать вымышленные сообщения, метрики, балансы, состояния интеграций или нефункциональные кнопки.

## Цветовые токены

| Токен | Значение | Назначение |
|---|---|---|
| `--color-background` | `#0B0B0D` | Основной фон |
| `--color-sidebar` | `#101013` | Боковая панель |
| `--color-surface` | `#151519` | Карточки и поверхности |
| `--color-hover` | `#202027` | Hover/active |
| `--color-text` | `#F5F5F7` | Основной текст |
| `--color-text-secondary` | `#92929D` | Вторичный текст |
| `--color-text-muted` | `#686873` | Приглушённый текст |
| `--color-border` | `#292930` | Границы |
| `--color-accent` | `#8B7CFF` | Основной акцент |
| `--color-accent-hover` | `#9B90FF` | Hover акцента |

Семантические success/warning/error цвета должны быть спокойными и иметь достаточный контраст; точные оттенки выбрать при реализации и проверить на доступность.

## Типографика и компоненты

Использовать читаемый sans-serif с единой шкалой размеров и плотностью, подходящей мобильному экрану. Целевой набор компонентов: `AppShell`, `Header`, навигация, кнопки, карточки, поля ввода, tabs/dialog/dropdown, статусы, пустые состояния, toast, skeleton и подтверждение опасных действий. Реализация и выбор библиотек остаются на следующих этапах.

## Запреты

Не использовать яркие градиенты, неон, сильное свечение/blur, декоративное 3D, лишние пустые области, случайные emoji вместо иконок, бессмысленные графики и фальшивые числа. Цвета реализации должны ссылаться на tokens, а не дублировать HEX по компонентам.
